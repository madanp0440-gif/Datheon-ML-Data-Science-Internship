### 🔹 Task 2 – Housing Price Prediction

**Objective:** Build and compare regression models to predict median house values using the California Housing dataset.

**Machine Learning Algorithms:**
- Linear Regression
- Ridge Regression
- Lasso Regression

**Workflow:**
1. Load and explore the California Housing dataset.
2. Inspect data quality and perform preprocessing.
3. Conduct exploratory data analysis and correlation analysis.
4. Engineer useful housing-related features.
5. Split the dataset into training and testing sets.
6. Train Linear, Ridge, and Lasso regression models.
7. Tune regularization parameters using cross-validation.
8. Evaluate models using RMSE, MAE, and R².
9. Visualize actual versus predicted values and residuals.
10. Identify the best-performing model based on the test results.

**Project files:**
- Jupyter Notebook: `Task_2_Housing_Price_Prediction.ipynb`
- Documentation: `Task-2/README.md`

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Datheon-ML-Data-Science-Internship.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Navigate to the project folder

```bash

```

### 3. Install the required libraries

```bash

```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required notebook and run its cells sequentially.

## 📊 Evaluation Metrics

Task 2 uses the following metrics to assess regression performance:

| Metric | Purpose |
|---|---|
| RMSE | Measures prediction error and penalizes larger errors |
| MAE | Measures average absolute prediction error |
| R² Score | Measures the proportion of target variation explained by the model |

Actual results and model comparisons are available in the relevant notebook.
